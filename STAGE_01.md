## Схема SQLite

- Версия схемы хранится в `PRAGMA user_version`, сейчас **1**. Команды чтения открывают существующую базу в режиме `mode=ro` и отклоняют неизвестную версию.
- В таблице `discs` положительный номер `disc_num` служит целочисленным первичным ключом. Метка `volume_label` и тип `media_type` берутся из экспорта. Повторение номера в разных строках одного диска допустимо при совпадении его метки и типа.
- В таблице `entries` хранятся ключ `id`, внешний ключ `disc_num` с каскадным удалением, вид `kind` (`File` или `Folder`), родительский путь `parent_path`, исходное имя `name`, расширение `extension`, 64-битный неотрицательный `size_bytes`, исходные `modified_date` и `modified_time`. У корневых элементов `parent_path` пуст, у остальных путь хранится с разделителем `\` и без начального разделителя.
- Виртуальные поля `display_name` и `full_path` вычисляются из сохранённых полей. Ограничение `UNIQUE (disc_num, kind, full_path)` отклоняет повтор логического ключа с исходным регистром. Индекс `entries_by_parent (disc_num, parent_path)` поддерживает выборку содержимого папки. Ссылка на папку проверяется после чтения всех элементов, поэтому порядок записей в XML произвольный.
- Поле `name_folded` хранит результат Python `str.casefold()` для отображаемого имени. Поиск по произвольной подстроке делает проход по этим значениям через SQLite `instr` и возвращает все совпадения, включая одноимённые элементы на разных дисках.
- Для импорта используются `foreign_keys=ON`, `journal_mode=DELETE` и `synchronous=FULL`. После штатного закрытия достаточно одного `catalog.db`.

## Импорт и обработка ошибок

Импортёр читает XML блоками, удаляет только байты C0 (`0x00–0x1F`), запрещённые XML 1.0, и сохраняет TAB, LF и CR. Он считает удалённые байты, проверяет UTF-8 и передаёт результат потоковому XML-парсеру. Источник открывается на чтение. В базу попадают поля каталога, а исходный XML, `DESCRIPTION` и `CRC` не сохраняются.

Данные записываются одной транзакцией во временный файл рядом с целевой базой. Перед публикацией сверяются номера дисков и показатели из `XML_AUDIT.md`, контрольные файлы из `SPEC.md`, количества прочитанных и записанных элементов, целостность SQLite, внешние ключи и дерево папок. После закрытия проверенной базы файл атомарно переименовывается на Windows. Уже существующий файл сохраняется, в том числе если он появился в момент параллельного запуска.

Ошибки данных указывают номер записи и диск, когда его удалось прочитать. Для синтаксической ошибки XML сообщаются позиция парсера и последний обработанный диск. При штатном завершении с ошибкой временная папка убирается. Принудительное завершение процесса может оставить папку `.catalog-import-*` с промежуточными файлами. Повторный запуск создаёт свою временную папку.

## Испытания

Все **12 автоматизированных тестов прошли**. Они проверяют UTF-8 и запрещённые байты, регистронезависимый кириллический поиск, корневые и вложенные элементы до глубины 12, файлы без расширения и с именем вида `.DS_Store`, даты и размеры, типы носителей, пропуск №36, одноимённые файлы на разных дисках, дубликаты ключа, конфликт метаданных одного номера, потерянного родителя, битый XML и UTF-8, неполный архив, прерывание с повторным запуском и защиту при одновременной публикации. Нехватка места проверена имитацией ошибок SQLite и файловой операции.

На полном архиве дополнительно проверены повторный запуск с уже существующим `catalog.db` (код 1), принудительное завершение процесса во время записи во временную БД и повторный импорт полного архива в ту же папку.

Проверки выполнены на Windows 10 x64. Запуск на Windows 11, физическое заполнение тома и отключение питания не проверялись. Команда импорта сверяет показатели именно этого полного экспорта. Режим обхода архивных показателей используется только из Python в тестовых фикстурах.

## Проверка в Windows PowerShell

Из папки проекта под Python 3.12 или новее, доступным как `python`

```powershell
python -X utf8 -m unittest discover -s tests -v
python -X utf8 -m catalog check
python -X utf8 -m catalog disc 1514
python -X utf8 -m catalog disc 1515
python -X utf8 -m catalog search 'ьЮРЕК'
python -X utf8 -m catalog search 'Slavneft'
```

Чтобы воспроизвести импорт с сохранением готовой базы, выберите свободное имя в существующей папке.

```powershell
python -X utf8 -m catalog import --xml .\input\whereisit.xml --db .\catalog-verify.db
python -X utf8 -m catalog check --db .\catalog-verify.db
```

Без параметров `import` читает `input/whereisit.xml` и публикует `catalog.db`, если это имя свободно.
