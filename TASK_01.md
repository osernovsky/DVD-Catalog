# Задача Codex №01: SQLite и безопасный импорт полного архива

Прочитай `README.md`, `SPEC.md`, `AGENTS.md` и `XML_AUDIT.md`. Реализуй **только** первый этап, без графического интерфейса и без сканирования CD/DVD.

## Содержание работы

1. Создай структуру небольшого поддерживаемого Python-проекта, ограничь зависимости стандартной библиотекой для первого этапа. Добавь `pyproject.toml` при необходимости, тесты и инструкции запуска в Windows PowerShell.
2. Разработай и задокументируй схему SQLite для дисков и элементов, индексы, версию схемы, ограничения уникальности, внешние ключи. Выключи зависимость от постоянного WAL.
3. Реализуй потоковый импорт `input/whereisit.xml` с безопасным отбрасыванием только XML-недопустимых управляющих байтов (счётчик в отчёте). Не меняй оригинальный XML. Используй streaming XML parsing (`iterparse` или эквивалент) для умеренного потребления памяти.
4. Собирай полный относительный путь, сохраняй точные имена/расширения, размеры, DATE/TIME, номера дисков, метки и типы носителей. Поддержи глубину 11+, файлы в корне и без расширений, размеры >4 GiB. Убедись, что количество файлов/папок и связность верны.
5. Импорт должен формировать **новую временную БД**, запускать `PRAGMA integrity_check`, сравнивать рассчитанные показатели с `XML_AUDIT.md` и только затем атомарно устанавливать `catalog.db`; существующий файл не заменять автоматически.
6. Обеспечь атомарность при аварии, неверном XML, нехватке места, отмене/прерывании импорта. Никакой частично готовой БД под именем `catalog.db`.
7. Реализуй простую командную проверку базы: число дисков/папок/файлов, пропущенные номера, диск 1514/1515, произвольный поиск по Unicode casefold через подстроку и проверку целостности.
8. Напиши и запусти тесты: корректный XML, контрольные символы, кириллица, разные типы носителей, файлы без EXT и в корне, вложенные папки, >4GiB, один и тот же файл на разных дисках, защита от дубликатов в одном диске, сохранение №36 как пропуска, невозможность замены базы без подтверждения, битый XML, повторный запуск.

## Приёмка этапа

Представь пользователю по-русски итоговый протокол с реальными данными из `whereisit.xml`: **1516 дисков, 16322 папки, 149960 файлов, 166282 записей, №36 отсутствует, последний номер 1517, следующий предлагаемый 1518**. Покажи результат `PRAGMA integrity_check`, число исправленных недопустимых XML байтов и число непривязанных/дублированных элементов. Сообщи размер сформированной `catalog.db`, команды для воспроизводимого тестирования и список созданных файлов.

Если полного XML нет в папке `input/`, сначала попроси пользователя скопировать его туда. Не подменяй реальный импорт синтетическими примерами и не переходи к этапу 2 до явного согласия пользователя.
