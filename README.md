# DVD Catalog — стартовый комплект для Codex

Цель: разработать **простое портативное офлайн-приложение для Windows 10/11**, заменяющее WhereIsIt при работе с архивными CD/DVD. Рабочий процесс согласован с пользователем.

## Как начать

1. Скопировать этот комплект в новую локальную папку проекта, например `D:\Projects\DVD-Catalog\`.
2. Положить **полный** экспорт WhereIsIt `whereisit.xml` в подпапку `input\` (создать папку самостоятельно). Исходный XML — **только для чтения**, не изменять. Не включать его в Git.
3. Открыть папку проекта в Codex и начать с содержимого `TASK_01.md`.
4. **Не переходить к интерфейсу**, пока этап 1 не завершён и пользователь не примет сверку импорта.

## Материалы

- `SPEC.md` — согласованное ТЗ и критерии готовности программы.
- `AGENTS.md` — постоянные правила работы разработчика/Codex.
- `TASK_01.md` — единственное задание на первый этап: база и импорт.
- `TASK_02.md` — главное окно, поиск и удаление записей диска.
- `XML_AUDIT.md` — результаты независимой проверки предоставленного экспорта.

## Принцип этапов

1. **SQLite + безопасный импорт XML + тесты и сверка.**
2. **Главное окно, поиск и удаление через контекстное меню**, проверка на копии реального каталога.
3. **Добавление записанного DVD/CD.**
4. **Портативная сборка Windows**, восстановление из `catalog.db` и приёмочные испытания.

Конечному пользователю не требуется Python или среда разработки; во время разработки инструменты могут потребоваться.

## Запуск интерфейса из исходников

В Windows PowerShell из папки проекта, с установленным Python 3.12+ x64

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m catalog gui
```

Интерфейс открывает готовый `catalog.db` из папки проекта. Для проверки добавления или удаления запустите его на отдельной копии.

```powershell
$testDb = Join-Path $env:TEMP ("dvd-catalog-" + [guid]::NewGuid() + ".db")
Copy-Item -LiteralPath .\catalog.db -Destination $testDb
.\.venv\Scripts\python.exe -m catalog gui --db $testDb
```
