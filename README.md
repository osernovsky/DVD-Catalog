# DVD Catalog

DVD Catalog — портативный офлайн-каталог записанных CD и DVD для Windows 10/11 x64. Он сохраняет имена, пути и метаданные файлов и папок в локальной базе SQLite. Каталог остаётся доступен после извлечения диска. Для запуска готовой сборки достаточно распаковать ZIP.

## Возможности

- Просмотр дисков по номерам и содержимого выбранного диска в дереве. В таблице видны имена, расширения, размеры и даты.
- Поиск файлов и папок по части имени без учёта регистра, в том числе на кириллице. Результаты показывают номер диска и путь к найденному элементу.
- Добавление записанных CD/DVD через оптический привод. Программа предлагает следующий свободный номер после последнего диска, запрещает повторы и автоматически открывает лоток после успешного сохранения.
- Удаление диска из каталога через контекстное меню с подтверждением. Удаляются записи в базе.
- Перенос и резервирование каталога копированием файла catalog.db при закрытой программе. Размер и положение окон, ширина панелей и колонок сохраняются в профиле Windows.

Программа считывает файловые метаданные. Содержимое файлов и качество записи она не проверяет.

## Первый запуск

1. Распакуйте DVD-Catalog-v1.0.0-beta.1-Windows-x64.zip в новую папку с правом записи.
2. Запустите DVD-Catalog.exe. Оставьте рядом папку _internal и файл catalog.db. База из этого архива изначально пуста.
3. Вставьте записанный диск, нажмите «ДОБАВИТЬ ДИСК», проверьте номер и нажмите «Сканировать». Первый предлагаемый номер — 1. Если привод отклонит извлечение, программа покажет сообщение, а запись сохранится.
4. Чтобы найти файл или папку, нажмите «ПОИСК», введите часть имени и нажмите Enter или «Найти».

## Обновление и резервная копия

Закройте программу и сделайте резервную копию catalog.db. Распакуйте DVD-Catalog-v1.0.0-beta.1-Update-Windows-x64.zip в отдельную папку, скопируйте свою базу рядом с новым EXE и запустите программу. Архив обновления поставляется без базы. Для восстановления используйте сохранённый catalog.db при закрытом приложении.

## Сборка и тесты

### Один исполняемый файл

Для однофайловой сборки установите зависимости из раздела ниже и выполните

```powershell
.\.venv\Scripts\python.exe -X utf8 build_onefile.py
```

В папке `dist/DVD-Catalog-OneFile/` будут только `DVD-Catalog.exe` и новая пустая `catalog.db`. ZIP `dist/DVD-Catalog-OneFile-Windows-x64.zip` содержит эти же два файла. Библиотеки и тексты лицензий упакованы в EXE. При запуске библиотеки распаковываются во временную папку Windows, которая удаляется после штатного закрытия. Поэтому запуск может занимать несколько дополнительных секунд.

Для обновления закройте программу и скопируйте новый EXE в отдельную папку вместе с копией своей базы. Существующую базу сохраняйте. Повторная сборка требует новой папки вывода, которую можно указать через `--output`.

### Сборка с отдельной папкой библиотек

Выполните в PowerShell на Windows x64 с 64-разрядным Python 3.12 или новее. Для сборки используйте отдельную копию исходников с чистым `dist`.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -X utf8 build_portable.py
.\.venv\Scripts\python.exe -X utf8 prepare_release.py --bundle dist/DVD-Catalog
```

Два ZIP появятся в `dist/release/`. Скрипт создаёт пустую базу по действующей схеме и формирует руководство для архивов из этого README. Для запуска интерфейса из исходников укажите путь к существующей базе, например к тестовой копии.

```powershell
.\.venv\Scripts\python.exe -m catalog gui --db .\test-catalog.db
```

## Миграция из WhereIsIt

В проекте есть служебная команда миграции из исходного полного экспорта WhereIsIt в UTF-8. Она сверяет номера дисков и показатели конкретного архива. Импорт читает исходный XML и создаёт отдельный SQLite-файл. Если целевой файл уже существует, команда завершится с ошибкой.

```powershell
.\.venv\Scripts\python.exe -m catalog import --xml input/whereisit.xml --db imported-catalog.db
.\.venv\Scripts\python.exe -m catalog check --db imported-catalog.db
```
